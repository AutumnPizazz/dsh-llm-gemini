# 项目隐私约定

源码、文档和测试示例只保留通用配置与公开上游信息，不写入开发机器的用户名、home 绝对路径、私有端点、API key、邮箱或真实凭据引用。

安装目录由脚本自身位置、参数与 DSH home 计算。仓库中的依赖链接与 profile 中新增的 `link:` 登记使用相对路径。`node_modules/`、本地验证产物和覆盖率文件不进入 Git。提交作者沿用本机已配置的 Git 身份，不由项目另设姓名或邮箱；作者元数据按 Git 配置记录。

示例使用公开 Google 地址或保留的 `.invalid` 域名。测试使用隔离的合成密钥和 loopback 模拟端点，运行结束后清理临时 profile。测试不会读取用户的模型设置文件。

安装登记备份保存在目标 profile 的 `.plugin-manager/backups/`，不复制到项目。插件本身使用 DSH 原有凭据服务，不新增密钥存储。
